# カスタムテンプレート（ユーザー登録）

このフォルダには、ユーザーが持ち込んだ画像から登録したカスタムテンプレートが保存されます。

## 命名規則

| ファイル種別 | 命名規則 | 例 |
|---|---|---|
| サンプル画像 | `template_XX_<名前>.png` または `.jpg` | `template_09_my_design.png` |
| プロンプトファイル | `template_XX_<名前>.md` | `template_09_my_design.md` |

- 番号は 09 から始まり、登録のたびに 10, 11... と増やす
- `<名前>` はユーザーが付けた任意の名前（英小文字・アンダースコア）
